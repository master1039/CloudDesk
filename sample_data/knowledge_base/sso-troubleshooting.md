# Enterprise SSO checks

Confirm the incident dashboard first. Then verify the identity-provider certificate, audience, callback URL, and clock synchronization. Capture a request ID and SAML error code without collecting the assertion itself.

## Escalation

Escalate an enterprise-wide outage to the identity team with timestamps and the affected domain.
