# Workspace access

Viewers can read shared content, members can collaborate, and administrators manage workspace-wide settings. Folder-level restrictions can further reduce access.

## Diagnosis

Compare the user's current role, group membership, and folder policy. Apply least privilege and require administrator authorization for role changes.
