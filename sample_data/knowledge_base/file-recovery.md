# Missing content

Check activity history, trash, retention policies, moved folders, and permission changes. Record file and folder identifiers without copying document contents.

## Data-loss cases

Potential data loss requires immediate escalation to storage reliability. Do not overwrite, recreate, or purge the affected location.
