# Seat billing

Seat reductions apply at the next renewal unless the contract says otherwise. Compare the invoice period with the seat-change history before proposing an adjustment.

## Refund safety

Refund requests are never executed automatically. Record the amount and reason, then obtain human approval before using the refund tool.
